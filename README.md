# Expo React Native App

This is a boilerplate React Native app built with Expo. It is designed to be easily distributed to the Apple App Store and Google Play Store.

## Getting Started

To get started with this project, follow the instructions below.

### Prerequisites

Make sure you have the following installed:

- Node.js (version 14 or later)
- Expo CLI

### Installation

1. Clone the repository:

   ```
   git clone https://github.com/yourusername/expo-react-native-app.git
   ```

2. Navigate to the project directory:

   ```
   cd expo-react-native-app
   ```

3. Install the dependencies:

   ```
   npm install
   ```

### Running the App

To run the app in development mode, use the following command:

```
npm start
```

This will start the Expo development server. You can then scan the QR code with the Expo Go app on your mobile device or run it in an emulator.

### Building for Production

To build the app for production, you can use the following commands:

- For iOS:

  ```
  expo build:ios
  ```

- For Android:

  ```
  expo build:android
  ```

Follow the prompts to complete the build process.

### Folder Structure

- `src/components`: Contains reusable components.
- `src/screens`: Contains the main screens of the app.
- `src/navigation`: Contains the navigation setup for the app.
- `src/types`: Contains TypeScript types and interfaces.
